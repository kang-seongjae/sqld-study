# 카드 추가하는 법 (`data/cards.json`)

구조는 **과목 → 단원 → 카드**이고, 카드마다 퀴즈를 붙일 수 있어요.
과목과 단원은 SQLD 공식 출제 범위(데이터자격검정 dataq.or.kr의 SQL 개발자 과목·주요항목·세부항목)대로 미리 만들어 두었어요.
빈 단원의 `"cards": []` 안에 카드를 넣으면 돼요.

```json
{
  "group": "SQL 기본",
  "name": "SELECT 기본과 WHERE 조건",
  "topics": ["SELECT 문", "WHERE 절"],
  "cards": [
    {
      "id": "select-basic",
      "title": "SELECT 문의 기본 모양",
      "summary": "한 줄 요약",
      "desc": "처음 배우는 사람을 위한 쉬운 설명. 줄을 바꾸려면 \n 을 써요.",
      "analogy": "일상 비유",
      "sql": "SELECT 이름\nFROM 사원;",
      "pitfalls": ["헷갈리기 쉬운 점 1", "헷갈리기 쉬운 점 2"],
      "oracle": ["오라클과 SQLite가 다른 점"],
      "exam": "시험에서 어떤 식으로 묻는지",
      "quiz": [
        {
          "q": "문제",
          "choices": ["보기1", "보기2", "보기3", "보기4"],
          "answer": 2,
          "explain": "해설"
        }
      ]
    }
  ]
}
```

## 단원 항목

| 항목 | 필수 | 설명 |
|---|---|---|
| `name` | 예 | 단원 이름. 단원 고르는 목록에 나와요 |
| `group` | | 공식 주요항목(예: SQL 기본, SQL 활용, 관리 구문). 목록에서 이걸로 묶여요 |
| `topics` | | 이 단원이 다루는 공식 세부항목. 이름과 같으면 생략해요 |

## 카드 항목

화면에는 아래 순서대로, 항목마다 제목이 달린 구역으로 나와요. 비워 둔 항목은 화면에서 빠져요.

| 항목 | 필수 | 화면 제목 | 설명 |
|---|---|---|---|
| `id` | 예 | | 카드마다 다른 영어 이름. **한 번 정하면 바꾸지 마세요**(오답노트가 이 이름으로 문제를 기억해요) |
| `title` | 예 | | 카드 제목 |
| `summary` | | (파란 상자) | 한 줄 요약 |
| `desc` | | 쉽게 풀어 보면 | 설명 |
| `analogy` | | 비유로 이해하기 | 일상 비유 |
| `sql` | | 예시 SQL | 예제 테이블(`사원`, `부서`)에서 실행되는 SQL. "연습창으로 보내기" 버튼과 **실행 결과 표가 자동으로** 붙어요 |
| `pitfalls` | | 헷갈리기 쉬운 점 | 문장 목록 `[ "...", "..." ]` |
| `oracle` | | 오라클과 SQLite가 달라요 | 문장 목록. 하나라도 있으면 제목 옆에 "오라클과 다름" 표시가 붙어요 |
| `exam` | | 시험에서는 이렇게 물어요 | 출제 방식 설명. 그 아래에 이 카드의 퀴즈가 "직접 풀어보기"로 나와요 |
| `quiz` | | | 객관식 문제 목록. 보기는 꼭 4개, `answer`는 정답 번호 1~4. 오늘의 퀴즈에도 섞여 나와요 |

## 주의

- 퀴즈는 **목록 끝에 추가**하세요. 중간에 끼우거나 지우면 순번이 밀려서 오답노트 기록이 다른 문제와 섞일 수 있어요.
  꼭 순서를 바꿔야 하면 문제에 `"id": "select-where-null"`처럼 고유한 id를 직접 달아 두세요.
- JSON 안에서 큰따옴표는 `\"`로 써요. 쉼표 하나만 빠져도 JSON이 깨져요. 앱을 열면 무엇이 잘못됐는지 화면에 보여 주고, `python tests/run_tests.py`로도 확인할 수 있어요(예시 SQL이 실제로 실행되는지도 검사해요).
- 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 브라우저에 반영돼요(예: `'v2'` → `'v3'`).
