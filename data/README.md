# 카드 추가하는 법 (`data/cards.json`)

구조는 **과목 → 단원 → 카드**이고, 카드마다 퀴즈를 붙일 수 있어요.

```json
{
  "subjects": [
    {
      "name": "2과목 SQL 기본과 활용",
      "units": [
        {
          "name": "SQL 기본",
          "cards": [
            {
              "id": "select-where",
              "title": "SELECT와 WHERE",
              "desc": "짧은 설명. 줄을 바꾸려면 \n 을 써요.",
              "sql": "SELECT 이름\nFROM 사원;",
              "quiz": [
                {
                  "q": "문제",
                  "choices": ["보기1", "보기2", "보기3", "보기4"],
                  "answer": 2,
                  "explain": "해설(없어도 돼요)"
                }
              ]
            }
          ]
        }
      ]
    }
  ]
}
```

| 항목 | 필수 | 설명 |
|---|---|---|
| `id` | 예 | 카드마다 다른 영어 이름. **한 번 정하면 바꾸지 마세요**(오답노트가 이 이름으로 문제를 기억해요) |
| `title` | 예 | 카드 제목 |
| `desc` | | 짧은 설명 |
| `sql` | | 예시 SQL. 있으면 "연습창으로 보내기" 버튼이 생겨요. 예제 테이블은 `사원`, `부서` |
| `quiz` | | 객관식 문제 목록. 보기는 꼭 4개, `answer`는 정답 번호 1~4 |

- 1과목 등 다른 과목은 `subjects`에 `{ "name": "...", "units": [...] }`를 하나 더 넣으면 돼요.
- 퀴즈는 **목록 끝에 추가**하세요. 중간에 끼우거나 지우면 순번이 밀려서 오답노트 기록이 다른 문제와 섞일 수 있어요.
  꼭 순서를 바꿔야 하면 문제에 `"id": "select-where-null"`처럼 고유한 id를 직접 달아 두세요.
- 쉼표 하나만 빠져도 JSON이 깨져요. 앱을 열면 무엇이 잘못됐는지 화면에 보여 주고, `python tests/run_tests.py`로도 확인할 수 있어요.
- 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 브라우저에 반영돼요(예: `'v1'` → `'v2'`).
